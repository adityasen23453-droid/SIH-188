The Operational Context: SSB Border Checkpoints

The client agency is Sashastra Seema Bal (SSB). Unlike airport immigration counters (which handle mostly international ePassports), the SSB guards the 1,751 km Indo-Nepal border and the 699 km Indo-Bhutan border. These are open borders governed by historic bilateral treaties:

  1. Indian and Nepalese/Bhutanese citizens do not require a passport or visa to cross overland Integrated Check Posts (ICPs like Raxaul, Sonauli, Jogbani, Panitanki). They travel using domestic identification documents: Voter IDs (EPIC), Aadhaar cards, Driving Licenses, Embassy Identity Slips, and Border Transit Permits.
  2. Third-country nationals (foreigners) must present standard Passports, valid Indian Visas (e-Visa or sticker), and physical border entry/exit ink stamps.
  3. Core Threat Vectors: Trans-border smuggling syndicates, illegal immigration, and cross-border operatives frequently exploit this open border using counterfeit Voter IDs/Aadhaar cards, altered DOBs on permits, tampered immigration ink stamps, swapped portrait photos, and identity impersonation (using multiple identities under different names).
  4. Theme Alignment: The problem is explicitly classified under Blockchain & Cybersecurity. Developing computer vision models alone will fail the evaluation criteria if the immutable audit trail, zero-knowledge verification, and tamper-evident data custody are missing.
Operational Imperative
At peak transit hours, border checkpoints process thousands of crossings. Manual verification causes severe congestion. The screening solution must execute across OCR, forensic tamper analysis, facial biometrics, and registry validation within under 2.5 seconds.

4. Deep Dive into the 6 Core Modules

Module 1: Universal OCR & Document Understanding

  • Perspective Correction & Preprocessing: Automatically rescales input images, computes Gaussian blur, detects quadrilateral document borders using cv2.approxPolyDP, and maps them to a top-down view with cv2.warpPerspective. CLAHE eliminates uneven illumination and checkpoint glare.
  • Dual-Zone Extraction:
    • MRZ Extraction: Utilizes PassportEye and Tesseract with tight character whitelisting and scoped positional letter-to-digit auto-correction (e.g. O→0, I→1, B→8 in numeric slices).
    • VIZ Extraction: Utilizes PaddleOCR for free-text fields (holder name, address, father's name) and regex parser for Indian national documents (Voter ID, Aadhaar, Driving License).

Module 2: Document Validation (Rules & Standards)

  • ICAO Doc 9303 Checksums: Computes standard 7-3-1 modulo 10 check digits across passport number, DOB, expiry date, and composite line 2 check:
    Check Digit = (∑ Value(ci) × wi mod 3) mod 10, where w ∈ {7, 3, 1}
  • Aadhaar Verhoeff Algorithm: Implements the dihedral group D5 multiplication table to validate 12-digit Aadhaar UID numbers and detect transpositions.
  • VIZ-to-MRZ Cross-Check: Detects cases where text in the visual zone was altered (e.g. Photoshop name change) without updating the MRZ.

Module 3: Tampering Detection (Core AI Innovation)

  • Error Level Analysis (ELA): Re-compresses the image at JPEG Quality 90 and calculates absolute pixel variance:
    Diff(x,y) = | Ioriginal(x,y) - Iresaved(x,y) |
    Generates an amplified ELA heatmap where modified or spliced regions appear highlighted due to compression mismatch.
  • Pretrained ViT Forgery Classifier: Deploys a Hugging Face Vision Transformer (zodumair/document-forgery-detector) over alpha-blended ELA images to output AI tampering confidence.
  • EXIF Metadata Inspection: Scans metadata headers for graphic editing tools (Photoshop, GIMP, Canva, Snapseed) and flags stripped metadata.
  • Stamp & Seal Forensics: Analyzes ink color distribution (HSV color clustering) and edge continuity of border entry/exit stamps.

Module 4: Biometric Face Verification & Multi-Identity Detection

  • 1:1 Verification (Impersonation Defense): Auto-crops the document portrait, captures a live face frame from the checkpoint webcam, computes 512-dimensional ArcFace embeddings, and evaluates cosine similarity:
    Cosine Similarity = (u • v) / ( ||u|| ||v|| )
    Threshold calibrated: ≥ 0.65 (Match), 0.50–0.64 (Uncertain), < 0.50 (Mismatch / Impersonation).
  • 1:N Duplicate Identity Detection (Winning Feature): Every screened face is indexed in an in-memory FAISS vector database. If a live face matches an existing record with similarity > 0.70 under a different name or passport number, a "CRITICAL: Duplicate Identity / Alias Detected" security alarm is raised immediately.

Module 6: Blockchain & Cybersecurity Trust Layer

  • Zero Biometrics On-Chain: Complies with DPDP Act. Never stores names, photos, or raw biometric arrays on-chain.
  • Cryptographic Block Payload:
    Block = { Index, Timestamp, PrevHash, SHA-256(Doc), RiskScore, OfficerID, Nonce }
  • Dual-Authority Architecture: Simulates Issuing Authority (Org 1) and Border Screening Authority (Org 2) with immutable append-only verification.
